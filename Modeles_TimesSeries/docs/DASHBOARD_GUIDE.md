# Guide dashboard

## Objectif
Expliquer l’utilisation du dashboard Streamlit pour analyser les prédictions.

## Lancement
```bash
streamlit run dashboard_app.py
```

## Bonnes pratiques
- Filtrer par PRM pour comparer les profils de consommation.
- Vérifier la cohérence entre horizon de prédiction et période affichée.
- Contrôler les métriques avant toute décision métier.
